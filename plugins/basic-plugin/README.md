# Basic Plugin

This is a starter Codex plugin scaffold.

## Layout

- `.codex-plugin/plugin.json` - required plugin manifest.
- `skills/` - optional Codex skills exposed by the plugin.
- `hooks/` - optional hook configuration and hook scripts.
- `scripts/` - optional helper scripts used by skills or hooks.
- `assets/` - optional icons, logos, screenshots, and other static files.
